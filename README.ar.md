# YMD Video Preflight — فحص ملفات الفيديو قبل التسليم

أداة مفتوحة المصدر تعمل محليًا على الكمبيوتر وتطلع تقريرًا يساعد المونتير يراجع الملف قبل إرساله للعميل. لا ترفع الفيديو إلى الإنترنت ولا تعدّل النسخة الأصلية.

**هذه نسخة أولى 0.1.0.** المثال المرفق مصنوع للاختبار، ونرحب بتجارب المستخدمين وتقارير المشكلات القابلة لإعادة التشغيل.

## ماذا تفحص؟

- أبعاد الفيديو واتجاهه ونسبة عرضه ومعدل إطاراته وترميزه.
- فترات السواد والصمت وثبات الصورة، مع توقيت كل فترة.
- مستوى الصوت المتكامل LUFS وأعلى قمة فعلية dBTP.
- ملف ترجمة SRT اختياري: التوقيت والتداخل والنص الذي يمتد بعد نهاية الفيديو وطول السطر وسرعة القراءة التقريبية.

**التنبيه يحتاج مراجعة بشرية:** صورة ثابتة أو وقفة أو انتقال أسود قد تكون مقصودة. الأداة لا تحكم على جمال المونتاج أو صحة الكلام أو تطابق حركة الشفاه.

## التشغيل

1. ثبّت Python 3.10 أو أحدث، وFFmpeg الذي يحتوي على ffprobe. الروابط الرسمية موجودة في [README الإنجليزي](README.md).
2. افتح Terminal داخل مجلد المشروع بعد فك الضغط.
3. نفّذ:

```bash
python3 -m ymd_preflight "video.mp4" --output reports/my-review --profile vertical-social --language ar
```

استبدل `video.mp4` بمسار فيديوك، مع الحفاظ على علامتي التنصيص إذا فيه مسافات. في Windows يمكن استخدام `py` بدل `python3`.

إذا عندك ترجمة:

```bash
python3 -m ymd_preflight "video.mp4" --srt "captions.srt" --output reports/with-captions --language ar
```

افتح `report.html` من مجلد النتيجة. يوجد أيضًا `report.json` للأتمتة و`report.md` كملخص نصي. عناوين التقرير واتجاهه بالعربية؛ بعض الرسائل الفنية وأسماء فحوص FFmpeg تبقى بالإنجليزية في هذه النسخة.

## معاينة سريعة

افتح `examples/demo-report/report.html` لمشاهدة تقرير جاهز بدون تثبيت الأداة. التقرير مأخوذ من اختبار مصطنع مدته 8 ثوانٍ، فيه أخطاء مقصودة للتأكد من أن الفحوص تكتشفها.

## الإعدادات

| الاختيار | الغرض |
| --- | --- |
| `general` | مراجعة عامة دون فرض نسبة أبعاد |
| `vertical-social` | تفضيل نسبة 9:16 |
| `landscape` | تفضيل نسبة 16:9 |
| `square` | تفضيل نسبة 1:1 |

هذه تفضيلات قابلة للتعديل، وليست اشتراطات رسمية للمنصات. لا ترفع دقة فيديو منخفضة فقط لإخفاء تنبيه؛ راجع متطلبات العميل والمصدر أولًا.

يمكن تعديل `examples/custom-profile.json` واستخدامه مع `--profile-json`. استخدم مجلد نتيجة جديدًا في كل مرة، أو `--overwrite` لاستبدال التقارير القديمة فقط. لملف طويل يمكنك زيادة `--timeout` من 300 ثانية.

## للمساهمين

راجع [دليل المساهمة](CONTRIBUTING.md) و[خطة التطوير](docs/ROADMAP.md). نحتاج تجارب فعلية على أنواع فيديو مختلفة وتقارير مشكلات يمكن إعادة إنتاجها. لا ترفع ملفات عملاء أو تفاصيل خاصة إلى مشروع عام؛ استخدم عينة مصطنعة أو عينة لديك حق نشرها.
